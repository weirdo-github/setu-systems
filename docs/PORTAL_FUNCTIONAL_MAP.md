# Portal Functional Map

## setu systems

Route: `/`

The Setu Systems landing page presents the live product family and links to the active portals. It is intentionally simple and operational, not a marketing splash page.

## setu finance

Route: `/finance`

Core functions:

- Contract-first customer onboarding.
- Customer register and 360 views.
- Draft invoices and billing schedule.
- Payment confirmation and exception resolution.
- Gmail/Zelle sync.
- Receipt PDFs.
- Employee records, employee payments, contracts, and payslips.
- Operating expenses, refunds, and payables.
- Contract archive and downloads.
- Referral review and rewards.
- Feedback intake.
- Auth/security audit logs.
- AskSetu read-only operational assistant.

## setu referral

Route: `/referral`

Core functions:

- No-login public referral intake.
- Referrer gateway links.
- Existing customer or team-member identification.
- Prospect service selection.
- Finance-side review before reward routing.
- Relationship and reward history inside Finance.

## setu discover

Route: `/discover`

Core functions:

- Opportunity inventory.
- Client records and evidence criteria coverage.
- Hybrid matching with transparent score evidence.
- Email push and email log.
- Source registry.
- Daily source refresh.
- Review queue for low-confidence or changed opportunities.
- Finance engagement status gating.
- Media tracker for client-to-writer article assignments.
- Publisher/live-link capture and client media panel.

## setu media

Route: `/media`

Core functions:

- Dedicated media-writer login surface.
- Writer-specific assignment list.
- Article brief, EB-1A criterion, due date, and status tracking.
- Start, save work, and submit workflow.
- Work-log history for notes, drafts, and submissions.
- Completed assignment history.
- Server-side writer ownership enforcement.
